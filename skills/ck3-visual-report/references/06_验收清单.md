# 报告验收清单

## 先分清各层结果

| 层级 | 通过意味着什么 | 应保留的记录 |
|---|---|---|
| 文件完整性 | 字节、目录和清单一致 | 哈希清单与校验输出 |
| 来源匹配 | 实际来源文件存在，哈希及声明范围的提取结果吻合 | 来源副本、提取定位、来源校验结果 |
| 页面结构 | 章节、编号、锚点、卡数、内嵌资源、脚本语法符合合同 | 结构审计原始结果 |
| 浏览器功能 | 在指定环境中阅读、筛选、交互和退化行为符合预期 | 浏览器版本、视口、用例结果与截图 |
| 研究语义 | 来源、作用域、概率、单位、后继与原文经实质核对 | 证据台账、未解问题、实际审阅者与方法 |
| 游戏运行 | 指定游戏版本下实测结果与机制一致 | 存档／场景、操作、预期、实际、日志 |

前一层通过不能推出后一层通过。结构通过不能推出语义通过，来源匹配也不证明对原文的解释正确。不执行的项目记录“未执行”，缺条件记录“阻塞及原因”，不要空白冒充通过。页面身份为正式报告只说明它用于交付；边界报告允许正式交付，研究完成度须另外披露。

## 内容复核

按 `10_研究复核与来源校验.md` 和本次覆盖清单核对：完整故事及选项、必要源码、数值方向与单位、读取者、条件及局部系数、后继、原始保真和实质逐条教学。检查完整对象时不能以原始源码已收录代替正文解释。没有取得的调用定义逐项登记；否定结论不能越过这些缺口。

首屏、结果卡、正文、教学源码、底稿和来源台账使用一致的数值与证据等级。关键事实更正后重新生成并核对实际 HTML（网页），不只检查修订后的底稿。每项结论保留证据与缺口；缺项标部分完成，明确反证标失败，不为得到通过而删掉要求。

## 页面最低要求

- 16个研究维度有可追踪覆盖；可见章节数量按读者任务组织。不适用和待确认区分。首屏的主要收益、代价、后续和验证状态不用展开源码就能理解。
- 所有英文解释正文就地中文括注；代码和原文保真例外有明确边界。
- 流程边有触发理由；分支不顺排成必经路线。状态生命周期有持有者和清理边界。
- 事件范围声明与浏览器卡数吻合；目录级与详解级分开。来源、双源码或缺失原因可找。
- 原始摘录与实际来源范围匹配，历史已有中文注释、完整故事和动态标记保留；不把摘录自身哈希说成来源真实性或解释正确性证明。

## 浏览器用例

对本次真实生成页面测试桌面、390 和 320 像素窄屏，默认阅读与局部展开都检查无全页横向溢出、标题不遮挡、表格和长代码可读。展开一个细节时，其他段落与阅读位置应保持；来源跳转后应能回到原句。若确有全局视图切换，必须额外验证同一语义锚点续读，不能只验按钮有效。记录实际入口协议；以内存加载内容通过不能替代本地文件打开通过。

搜索一个命中词和不存在的词；按层级、类别、结果分别筛选；推荐开关；恢复默认；标题／权重排序；展开当前结果和收起全部。缺失权重不能显示为固定零概率。

禁用网页脚本后打开页面：全部章节可见，原生折叠可操作，静态例题结果完整；交互按钮不假装可用。检查无网络请求。脚本语法检查和真实浏览器加载检查分别执行。

计算器测适用的零值、边界百分比、超百分比、负数、空值、非整数周期、资金不足；非法输入不显示有效结果。没有计算器时记录不适用。打印准备应显示全部内容；返回后恢复原筛选、展开状态和阅读位置。模拟打印事件通过只证明状态切换，实际 PDF（便携文档）分页、裁切和物理打印另行记录。保留失败、修订和最终复测证据，不拿旧示范的通过记录覆盖新报告。

## 生成器反例

测试缺章节、重复编号、无效来源、二手报告误标一手源码、原始文本哈希被改、模板占位符混进正式报告、不可用源码链接、非有限权重和包含脚本标签的输入。输入转义后不得执行页面注入。

## 本包自动检查的限制

`audit_report.py`（页面结构审计脚本）不判断机制正确性或研究完成度，也不穷尽正文术语、跨文件历史链接、语义可达性、图形误导、原本地化完整性和自定义图表。

`verify_research.py`（研究记录与来源校验脚本）核对真实来源、摘录和复核记录，不会自动理解单位、作用域或教学质量。其“检查完成并已记录复核”状态仍是确定性检查与已提交记录的组合，不是自动语义通过。语义结论须来自实际复核；作者自查、独立代理审阅和人工审阅如实命名。扩展组件时补相应检查。

## 本地复核命令

```bash
python scripts/audit_report.py output/机制研究.html --json output/结构审计.json
python -X utf8 -B scripts/verify_research.py output/研究底稿.json --review output/研究复核清单.json --source-root inputs --json output/研究复核结果.json
python scripts/audit_browser.py output/机制研究.html --output output/浏览器验收
```

`audit_browser.py`（实际报告浏览器审计脚本）接受一个或多个真实 HTML（网页）路径，必须指定输出目录；可用 `--browser`（浏览器路径参数）指定兼容浏览器程序。结果与截图保存在该目录。缺少浏览器或运行库时记录未执行，不伪装成报告内容失败或通过；工具自身出错也与观察到页面失败分开。本精简包不附旧示范回归与旧发布清单；只审计本次实际生成的报告。

## 人物行为专项

- 直接特质与数值读取路径没有被错误串联。
- 特质贡献、当前读数、显示称谓、资格、评分与结果清楚分开。
- 每项输入写清读取谁，门槛保留例外。
- 未读到的属性没有凭常识补入；权重不冒充成功率。
- 原报告、教学算例、引擎实测分别标注；人物行为示范不是全量人工智能研究。

## 阅读连续性验收

按照 `11_连续阅读与原位深读.md`：记录默认正文量及主要任务路径；打开一个局部说明，检查触发位置与其他展开状态；进入源码后返回原句；搜索只帮助定位，不清空正在读的主线。不能用“结构通过、按钮能点”代替这些体验检查。
