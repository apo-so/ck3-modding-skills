# 当前桌面通道

先读当前提供方的官方computer-use技能与实际工具文档，严格按其初始化、输入与确认规则执行。配置项、安装文件或另一模型成功不证明本会话可用；执行只读应用/窗口枚举并唯一定位目标。浏览器桥只见浏览器不证明另一桌面工具不存在。

默认使用实际暴露的正式接口；用户指定且获授权的原生后台路线按其独立身份验证。没有可用通道时报告缺件，不用自写点击器绕过工具拒绝，不凭旧会话ID连接。

每步“观察 → 一项输入 → 刷新 → 后置状态”。窗口、布局、焦点或模态状态变化后更新观察；不复用旧截图坐标、索引或失效窗口对象。发送成功不是操作完成。读取工具直接显示的截图；不将屏幕发往未指定外部服务。

## 不抢鼠标的独立副屏

先复用项目已有的真实CK3后台按键、截图、滚动、释放与宿主端点证据，而非重复做隔离靶程序。某些API会激活目标，仅能限定那些API，不能据此否定专用后台路线。

新会话仍核对游戏版本/EXE哈希、进程身份、副屏、Mod加载、当前能力和独占写入者。旧桥已关闭/清理时不重连；能新建同方案会话与能重连旧桥分别判断。旧无Mod证据不证明当前Mod通过。

用户要求持续不抢焦点时，需目标本地输入、游戏源截图、宿主焦点/鼠标边界及操作释放证据；端点抽样不证明全过程。最小化窗口、虚拟桌面、把窗口移到副屏不自动形成隔离。独立虚拟机路线先证明guest与guest-local控制。

工具/用户中断后停止输入，保存已完成操作与未知状态。登录验证、系统安全与权限界面依当前工具规则处理。恢复先重新枚举观察，不盲重试，不擅自关闭或重启CK3。
