# 保存、部署与交接

路径以用户项目和固定入口为准，不硬编码工程盘符。沿用现有唯一活动目录，换人先读入口、progress、交接和最近journal；核对候选哈希、前任是否停止、未结束操作，再从next_action继续。

多阶段工作集中保存计划、源码候选、证据、runs/checkpoints/deployments；简单小改不建整套目录。只备份实际变更文件、必要原生证据与回滚，不反复复制全部存档或参考资料。

每个有意义步骤前记操作ID、目标、文件白名单、before哈希、预期和可重跑性；完成后存源码、diff、命令退出码和检查结果。关键小步后及持续工作至少每十分钟存检查点；长调用前存会话/日志位置，不擅设后台自动化。

progress记录run/执行者、授权、候选路径与哈希、最后有效检查点、未验证半成品、进程/操作、部署/加载证据、备份、待用户项和下一步。JSON先写临时文件并解析再替换，保留上一版。检查点核验完成才写COMPLETE；暂停写PAUSED_HANDOFF，未知磁盘改动保留UNVERIFIED。

部署须有授权，先记目标和before/candidate哈希，核验备份，再逐文件复制、读回after哈希并出回执。无完整回执时按before/candidate/current逐文件恢复现场，不能认定未部署；第三方修改不得覆盖。回滚同样检查当前哈希，保护用户后续改动。

迁移先复制核验再更新固定入口并留转向；跨机包附完整候选、进度、必要证据、哈希和缺件表，接收后更新路径映射。源码、静态、部署、实际加载与场景验收分别报告。

清理先列具体保留/删除清单并核验SHA256；用途或来源不明不删除。本技能不是历史项目批量清理授权。
