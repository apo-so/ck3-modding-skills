# CK3 游戏验证

先读 [桌面通道](../windows-computer-use-workflow/SKILL.md)，核对用户授权、游戏身份、当前日期/暂停状态、目标角色和本次加载的Mod候选。游戏控制工具属于外部依赖，本技能不提供能力或固定坐标。

## 选人

从当前前端状态进入目标年份及自由选人；有真实连接的原生桥时先查capabilities，剩余操作使用当前可用的正式UI工具。1066大辽目标优先通过头衔查找器查“大辽/辽”，打开实际结果核对持有人和角色卡；多结果逐项消歧，不凭地图位置或历史坐标认定目标。未获开局授权停在选中角色，不点Start。

随机可玩角色不等于指定角色；书签角色接口不必然支持任意CharacterID。原生与UI混合执行分别标NATIVE/UI_FALLBACK，不能称全原生通过。

## 五项检查（仅执行用户要求项）

1. **推进一个日历月与事件**：读D0和暂停状态，目标为下月同日，短月用月末。逐步观察日期；仅在授权允许时从实际可见随机事件选项均匀抽取并记录。遇到不明、战争/死亡、存档或系统弹窗先读清。达到日期并处理已遇事件后立即暂停，再复读日期稳定；不要边运行边写长日志。未出现事件单列说明，不造事件处理成功。
2. **人物页**：从当前头像打开，核对玩家身份，抄录清楚可见字段；模糊项标UNVERIFIED。
3. **主头衔**：从当前人物卡确认的头衔/徽记打开，核对持有人和等级；不点创建、篡夺、销毁。
4. **直属封臣互动菜单**：从实际封臣分组核对人物和直属关系，勿把朝贡者当封臣；右键打开菜单后观察，不执行互动。
5. **决议栏**：打开并读取分类、名称和可执行状态；只读检查不执行决议。

## Mod验收与恢复

另列本次功能场景、PRE/POST对象与资源，按 [运行探针](../ck3-runtime-probe/SKILL.md) 判定。界面能打开不证明动作发生。只在明确要求时保存战役或恢复存档；无真实逆操作不承诺恢复。

记录每项输入/返回、可见结果、截图/日志、实际后端、耗时、恢复次数、最终日期和暂停状态。计时从实际首个相关观察/输入起，说明是否含预检；不要从旧日志倒算本轮。逐项PASS/PARTIAL/FAIL/NOT RUN，不把工具准备或其他模型结果当亲测。
